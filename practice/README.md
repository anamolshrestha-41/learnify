# LPA - Learning Performance Analysis

## Real world problem:
Schools and colleges usually look only at the final exam marks.

They don't analyze:

Does attendance affect marks?
Does study time matter?
Does sleep affect performance?
Do students who use phones more perform worse?
Which students are at risk of failing?
Which subject needs more improvement?

Teachers often spend hours manually analyzing spreadsheets. 

## Solution

Build a Python + NumPy project that analyzes student learning behavior and automatically generates insights.

This is exactly the kind of work a Data Analyst performs.

- Python
- NumPy
